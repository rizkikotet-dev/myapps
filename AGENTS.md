# AGENTS.md

Guidance for AI coding agents working in this repository.

**Read [CLAUDE.md](CLAUDE.md) first — it is the canonical, maintained guide** (run commands, architecture of the modular frontend + stdlib backend, Roblox auth flow, and the load-bearing OGG CRC pipeline gotchas).

Quick orientation:

- **Structure:** NOT single-file. `index.html` is markup only; CSS lives in `css/base.css` (design tokens) + `css/app.css` (components); JS is one IIFE module per file under `js/`, loaded in a fixed order ending with `js/ui-extras.js`. Do not introduce a bundler.
- **Run:** `python server.py` → http://127.0.0.1:8000 (serves UI + `/api/*`). Verify via `GET /api/health`. No build/lint/tests exist; verify changes manually in the browser.
- **Never change:** element IDs referenced by `collectEls()` in `js/main.js`, class names generated by `js/files.js`/`js/urlfetch.js`/`js/roblox.js`, or the OGG CRC rewrite sequence documented in CLAUDE.md.
- `roblox_tokens.json`, `roblox_config.json`, `auth_config.json`, `auth_tokens.json` hold real credentials — never commit or print them.
- Auth flow: `login.html` (Google/Discord OAuth) → `index.html` auth gate → dashboard. Roblox login is separate (auto-upload feature).
- Backend: `server.py` — `python server.py --port 55501`. Tauri dev uses `dev_server.py` on 1430 + backend on 55501.

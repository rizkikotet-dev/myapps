1. Apa itu “Hidden Audio”?

Tool ini mengubah header OGG Vorbis — bukan re-encode berat. Audio tetap jernih (treble 100% tidak mendem) tapi file jadi 8–10× lebih kecil. Triknya: sample-rate asli (misal 44100 Hz) dikali kecepatan (misal 2.30 → 101430 Hz) lalu ditulis di header OggS. Saat diputar normal jadi chipmunk, tapi di Roblox Studio kamu turunkan PlaybackSpeed ke kebalikan (1/kecepatan) dan suara kembali normal.

Live: 2.30× → di Studio pakai 0.435 — Sound.PlaybackSpeed = 0.435

2. Kontrol Kecepatan (Speed)

  • Slider 0.5× – 4.0× (default 2.30×). Nilai >1 = lebih cepat & pitch naik (chipmunk).
  • Rumus wajib: PlaybackSpeed di Studio = 1 ÷ Speed di sini. Contoh 2.30× → 1/2.30 = 0.435.

3. Cara Pakai di Roblox Studio

  1. Upload hasil .ogg ke Roblox (Creator Dashboard → Audio) dapatkan rbxassetid://123456789.
  2. Di Explorer buat Sound instance:
local Sound = Instance.new("Sound")
Sound.SoundId = "rbxassetid://123456789" -- ganti ID audio kamu
Sound.PlaybackSpeed = 0.435 -- sesuaikan dengan 1/speed (contoh 2.30×)
Sound.Volume = 1
Sound.Parent = workspace
Sound:Play()
Jangan set PlaybackSpeed = speed yang sama di sini! Selalu gunakan kebalikannya. 2.30× di sini = 0.435 di Studio.

4. Mode Deploy (No Server Storage)

Hasil konversi tidak pernah disimpan di server — Auto Upload ON: langsung ke Roblox via OTT; OFF: langsung ke folder Downloads perangkat kamu. Aman untuk deploy publik, tanpa penumpukan file di server.
